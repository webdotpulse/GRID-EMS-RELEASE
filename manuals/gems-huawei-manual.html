🛑 Critical Rule: Strict Single-Master Limit on Port 502
Both the Huawei SDongleA-05 and EMMA-A02 allow only ONE active Modbus TCP client connection at a time.
  • Disconnect secondary polling clients: Ensure no other local automation server, script, or third-party wallbox is polling the Huawei dongle IP on port 502 simultaneously, or the dongle will drop TCP sockets with Connection reset by peer.
  • Reserve Static IPv4 Addresses: Create a DHCP reservation in the site router for both the Huawei SDongleA-05 / EMMA-A02 MAC address and the GEMS controller (or set a static IP under Settings → Network in GEMS). Especially on EMMA-A02, if GEMS changes IP address, EMMA will immediately refuse port 502 connections!

Section 3: Step-by-Step Huawei FusionSolar App Configuration

Standard homeowner plant views inside the FusionSolar mobile app hide communication security and energy control parameters. You must connect using Local Device Commissioning with Installer privileges (or use the FusionSolar Web Portal as an Installer).

3.1 Connecting Locally via FusionSolar Device Commissioning

  1. Disable Smartphone Mobile Data (Crucial Tip): Temporarily switch off cellular/4G/5G mobile data on your smartphone while keeping Wi-Fi enabled. Otherwise iOS and Android often route traffic away from the inverter's offline Wi-Fi hotspot.
  2. Open Device Commissioning: Open the FusionSolar App. On the login screen (or bottom tab bar under Me / Services), tap Device Commissioning.
  3. Scan Hardware QR Code: Scan the QR code sticker on the side of the SUN2000 inverter (or directly on the EMMA-A02 module if your site uses EMMA) to join its local Wi-Fi Access Point.
  4. Select Installer Account: Tap Installer and enter the site's Huawei Installer password configured during initial commissioning.

3.2 Enabling Modbus TCP on SDongleA-05 (Topology A)

Once inside the local commissioning dashboard of a SUN2000 inverter equipped with an SDongleA-05:

  1. Navigate to: Settings → Communication Configuration → Dongle Parameter Settings → Modbus-TCP
  2. Change Connection from Disabled to Enable (unrestricted) (or select Enable (restricted) and enter the exact static IPv4 address of your GEMS controller).
  3. Tap Confirm / Save. Port 502 is now active on the SDongleA-05 LAN IP.
  4. Verify the inverter's internal RS-485 Slave ID under Settings → Communication Configuration → RS485_1: confirm Protocol = MODBUS, Baud Rate = 9600, and note the Communication Address (factory default is 1; occasionally 2 or 16 on multi-inverter installations).
💡 Remote Alternative via FusionSolar Web Portal (Installer Login)
If you have remote Installer access to the plant in a desktop browser, you can unlock SDongle Modbus TCP remotely without visiting the site: go to Plants → Device Management → Expand Inverter → Select SDongleA-05 → Configuration (Set Parameters) → Connection Parameters → Modbus TCP → Enable (unrestricted).

3.3 Enabling Modbus TCP on Huawei EMMA-A02 (Topology B)

If your installation uses a Huawei EMMA-A02 instead of a Smart Dongle, scan the QR code on the front of the EMMA-A02 in Device Commissioning and apply all four settings below:

  1. Navigate to: Settings → Communication Configuration → Modbus TCP
  2. Set Modbus TCP Connection to Enable.
  3. Set TLS Encryption to Disable (OFF). (Mandatory: local industrial Modbus TCP on port 502 requires standard unencrypted frames; leaving TLS enabled causes immediate handshake failures).
  4. In Client IP Address, enter the exact IPv4 address of your GEMS appliance (for example 192.168.1.50). Do not enter 0.0.0.0—EMMA-A02 does not accept wildcard addresses and will reject connections unless the exact GEMS IP is listed.
  5. Disable Conflicting EMMA Cloud AI / TOU Schedules: Under EMMA's energy management mode, set battery operation to standard Maximum Self-Consumption and leave EMMA's cloud AI/TOU scheduling Disabled so EMMA never overrides GEMS setpoints.

3.5 Active Power Control & Smart Power Sensor Verification in FusionSolar

  • Active Power Control Mode (Settings → Power Adjustment → Active Power Control): Set to Unlimited (No Limit) unless your Distribution System Operator legally requires a hardwired physical cap. Why: If you enable static Zero Export inside FusionSolar, the inverter throttles PV production even during profitable export hours or Flemish Green Certificate (GSC) hours. Leaving FusionSolar on Unlimited lets GEMS dynamically allow profitable export and smoothly curtail SUN2000 output only when prices turn unprofitable!
  • Closed-Loop Controller (if visible): Select Inverter for single-inverter installations (fastest hardware response), or SDongle / SmartLogger only when operating multiple Master/Slave cascaded SUN2000 inverters.
  • Verify DTSU666-H / DDSU666-H CT Clamp Direction Before Onboarding: In FusionSolar's real-time power flow screen, turn on a known 2 kW household load (such as an electric kettle) with battery temporarily idle. Confirm that grid import rises by +2 kW on the matching phase and that all CT clamp arrows (K → L or P1 → P2) point from the utility meter toward the house distribution board. Reversed CTs or swapped phase voltage taps (Ua/Ub/Uc mismatched against Ia/Ib/Ic) will cause erratic battery charging/discharging!
⚠️ Post-Update Reminder: Re-Check Modbus TCP After Huawei Firmware Upgrades
Major remote firmware updates pushed to the SDongleA-05 or SUN2000 occasionally reset security permissions, reverting Modbus-TCP back to Disabled. If GEMS ever reports the Huawei inverter offline immediately following a Huawei firmware update, re-verify Step 3.2 in FusionSolar.

5.4 Coordinating LUNA2000 with EV Charging (Preventing Battery Drain into EVs)

A classic pitfall in hybrid battery homes occurs when an EV wallbox (such as a Raedian NEO / NEX / Gemini) starts a high-power 7.4 kW or 11 kW charging session at night: seeing sudden house import on the DTSU666-H, the Huawei inverter immediately dumps the entire LUNA2000 battery into the car, leaving the house without battery reserve for the expensive morning peak! Follow these best practices in GEMS to keep EV and LUNA2000 in harmony:

  • Connect EV Chargers Directly to GEMS via Modbus TCP (Preferred) or Native OCPP: Configure your Raedian wallbox in GEMS (Settings → Devices → EV Charger) via local Modbus TCP. Never wire or configure an EV charger to poll the Huawei SDongle directly.
  • Daytime Solar Charging (`PV Only` or `Eco` Mode): Keep the wallbox in PV Only (Solar) or Eco / Smart mode on the GEMS Dashboard. GEMS dynamically modulates EV current (6A–32A) from real-time solar surplus after house base load is covered.
  • Overnight Cheap Grid Charging Without Emptying LUNA2000: If you use Cheapest Spot Price Hours (e.g. 3 cheapest hours) or scheduled night EV charging, add a one-click Battery Cost Optimization Rule under Settings → Strategy → Rule-Based Battery Cost Optimization:
    • Action: Hold (Idle / No Export) (or Force Charge if spot prices are simultaneously ultra-low) during your night EV charging window (e.g. 01:00 – 05:00). Setting Hold instructs the Huawei inverter to pause LUNA2000 discharge while the car charges directly from cheap off-peak grid power, preserving 100% of your LUNA2000 charge for the expensive 07:00–09:00 morning household peak!

Section 6: Built-In Hardware Safeguards, Verification & Troubleshooting

6.1 How GEMS Protects Your Huawei Inverter & LUNA2000

  • 10-Minute Hardware Deadman Timer: Whenever GEMS commands active LUNA2000 forced charging or discharging, it programs a bounded 10-minute hardware duration window on the SUN2000 and refreshes it every 5 minutes. If a network switch loses power or GEMS is disconnected, the Huawei inverter automatically reverts to autonomous Maximum Self-Consumption within minutes—never leaving the battery stuck charging or discharging!
  • Live BMS Dynamic Power Clamping: Cold winter mornings (< 5 °C) and high State-of-Charge (> 90% SOC) cause LUNA2000's BMS to derate permissible charge wattage. GEMS continuously reads live LUNA2000 dynamic charge/discharge power limits and clamps setpoints automatically so commands are never rejected.
  • 250 ms SDongle Pacing & Scanner Protection: GEMS enforces a minimum 250 ms inter-frame recovery gap on Huawei Modbus buses and automatically excludes configured Huawei IP addresses from background port-502 network discovery sweeps so single-socket dongles never experience connection collisions.

6.2 6-Point Post-Commissioning Verification Checklist

✅ Mandatory Handover Checklist Before Leaving Site
  1. Device Online & Live Debug Probe: In Settings → Connected Devices, confirm Huawei Hybrid Inverter displays ● Online. Click Debug on the device card and verify non-zero Voltage (~230 V), accurate LUNA2000 SOC %, and plausible PV / Grid power values.
  2. Polarity Check on Dashboard: Boil a ~2 kW kettle with solar steady. Verify on the GEMS Dashboard that Home Consumption increases by ~2 kW and Grid Import (positive) or Battery Discharge rises accordingly—never inverted!
  3. Logger Cleanliness Check: Open the Logger tab and filter for HuaweiInverterPoller for 2 minutes. Confirm zero connection reset, i/o timeout, or illegal data address errors.
  4. FusionSolar Cloud Coexistence: Open the standard homeowner FusionSolar App (Plant View over cellular data) and confirm the plant still shows Online with live cloud telemetry updating every 5 minutes alongside GEMS.
  5. Configuration Backup: In Settings → System Info (Installer Mode), click Export Configuration Backup (.json) and store a copy with the site handover records.
  6. Re-Lock Homeowner View: Click the padlock icon in the Settings header to lock Certified Installer Mode so critical Modbus IDs, breaker limits, and strategy rules are protected against accidental taps.

6.3 Symptom Resolution & Troubleshooting Matrix

Observed Symptom Probable Root Cause Field Corrective Action
Connection refused or TCP RST on port 502 Modbus TCP is still Disabled in FusionSolar, or on EMMA-A02 TLS is ON / GEMS IPv4 is not whitelisted. Connect via FusionSolar Device Commissioning (Installer). On SDongle set Modbus-TCP = Enable (unrestricted). On EMMA-A02 disable TLS and enter the exact GEMS IPv4 address (never 0.0.0.0).
Intermittent i/o timeout or EOF every few minutes Second external client polling port 502, weak 2.4 GHz Wi-Fi at SDongle, or Poll Interval set too low (< 8s). Shut down any secondary Modbus polling software/scripts, wire Ethernet RJ45 into the SDongleA-05, and keep Poll Interval at 10 seconds in GEMS.
Connected via TCP, but registers time out (`Slave failure`) Wrong Modbus ID in GEMS (e.g. set to 1 while inverter RS485_1 address was changed to 2 or 16). Check Settings → Communication Configuration → RS485_1 in FusionSolar and enter that exact Communication Address as Modbus ID in GEMS.
LUNA2000 reads SOC %, but ignores grid charge commands or logs server device failure Charge from AC is Disabled in FusionSolar, Grid Charge Cutoff SOC is too low, meterless Topology D is locked in a meter-dependent mode, or outdated SDongle/SUN2000 firmware. In FusionSolar Energy Control, set Charge from AC = Enable, Grid Charge Cutoff SOC = 100%, and Max Charge/Discharge Power = Rated Max. If no Huawei meter is wired, leave Grid Meter Connected? unchecked in GEMS (and use Fixed Charge/Discharge with 0 slots if FusionSolar blocks Self-Consumption), and update SDongle firmware to SPC126+ / V200 SPC118+.
Battery charges from grid when house load rises, or exports unexpectedly DTSU666-H / DDSU666-H CT clamps installed backwards (L → K) or phase voltage wires swapped against CTs. Inspect distribution board: ensure all three CT arrows point Grid → House and phase L1/L2/L3 voltage taps match CT-A / CT-B / CT-C exactly.
Solar PV reads 0 W on a second cascaded Huawei inverter Only the Master inverter (Modbus ID 1) was added in GEMS; cascaded slave inverter was not onboarded. Add a second Huawei Hybrid Inverter device in GEMS pointing to the same SDongle/EMMA IP on port 502 with Modbus ID = 2 (GEMS shares one TCP socket automatically!).
SUN2000 does not curtail during negative export prices Allow Curtailment unchecked on device, Active Inverter Curtailment unchecked in Strategy, or GSC value still profitable. Check Allow Curtailment on the Huawei device card, enable Active Inverter Curtailment in Strategy, enter exact Rated Power (kW), and verify the Effective Curtailment Threshold banner.
Huawei stopped responding right after an overnight update Huawei remote firmware upgrade reset SDongle security permissions back to factory default (Disabled). Open FusionSolar Web Portal or local Device Commissioning as Installer and re-enable Modbus-TCP = Enable (unrestricted).
