1. Understanding the P1 User Port

Every modern digital utility electricity meter installed by distribution grid operators in Belgium (Fluvius, Sibelga, ORES, RESA), the Netherlands (Liander, Enexis, Stedin), and Luxembourg (Creos Smarty) features a physical customer port labeled P1.

The P1 port is a standardized serial communication interface designed specifically for homeowners and energy management systems. Unlike closed utility optical ports, the P1 port provides a unidirectional, real-time data stream directly from the utility revenue meter into GEMS.

What Data Does GEMS Read from the P1 Port?

3. RJ12 vs RJ11 Pinout & Electrical Specifications

The physical P1 receptacle on the smart meter is a standard 6-position, 6-contact (6P6C) modular socket (commonly referred to as an RJ12 socket).

💡 Can You Use an RJ11 (6P4C) Cable?

Yes! A standard telephone plug is physically an RJ11 (6P4C) connector. It has 6 plastic pin slots but only the center 4 slots contain metal contacts (corresponding to Pins 2, 3, 4, and 5 of the RJ12 socket).

Because Pin 2 (RTS / Request) and Pin 5 (Data) and Pin 3 (GND) are all located on the center pins, an RJ11 4-wire cable works perfectly for reading telemetry into GEMS! The only pin omitted on RJ11 is Pin 1 (+5V power output). Because GEMS connects to the Raspberry Pi's USB port, the USB dongle draws its 5V power from the Pi anyway, making Pin 1 optional!

4. Understanding Inverted Logic & Open-Collector

The most common reason why DIY P1 cables fail is signal inversion.

Standard TTL serial UART (e.g. from an Arduino or standard USB adapter) uses non-inverted logic:

  • Idle line = High (+5V / +3.3V) → Logic 1
  • Active start bit = Low (0V) → Logic 0

However, the DSMR / Fluvius P1 specification utilizes an open-collector output with inverted logic:

  • Idle line = Pulled Low (0V) → Logic 1
  • Active transmission = Pulled High (+5V) → Logic 0

If you connect Pin 5 directly to the RX pin of a standard USB serial converter, the operating system reads flipped 1s and 0s, resulting in completely garbled binary noise (framing errors, gibberish characters like \xff\xfc\x00).

To fix this, the signal must be inverted. GEMS gives you two clean options:

  1. Method A (Hardware Transistor Inverter): Place a single inexpensive NPN transistor (e.g. BC547) and a pull-up resistor between Pin 5 and the USB RX pin. Works with any USB-serial adapter (CH340, CP2102, FTDI, PL2303).
  2. Method B (FTDI Software Inversion): Use an authentic FTDI FT232RL or FT232R USB adapter. FTDI chips contain internal logic gates that can invert the RX polarity in hardware EEPROM without adding any external transistors!

6. Method A: Hardware Transistor Inverter Build

This circuit works universally with every USB-serial chip on the market (CH340G, CP2102, PL2303, FTDI, Raspberry Pi GPIO UART).

Circuit Schematic

SMART METER P1 PORT USB-UART ADAPTER (e.g. CH340 / FTDI) =================== ==================================== [ Pin 2: RTS ] ─────────────────────────────────────────── [ +5V VCC Pin ] (Pulls RTS HIGH to activate streaming) [ Pin 3: GND ] ─────────────────────────────────────────── [ GND Pin ] (Common Signal Ground) +5V (from USB) │ ┌┴┐ │ │ R1 (1 kΩ Pull-up) └┬┘ ├──────────── [ RXD Pin ] (Inverted TTL Input) │ C │ [ Pin 5: TXD ] ────[ 10 kΩ R2 ]────┤ BC547 (NPN Transistor) B ╲ │ E │ [ Pin 3/6: GND ] ────────────────────┴──────────── [ GND Pin ]

How the Transistor Circuit Operates

  1. When P1 Pin 5 is Low (0V / Idle), no current flows into the base of the BC547. The transistor is OFF (open). Resistor R1 pulls the USB adapter's RXD pin up to +5V (High). This matches the standard UART idle state!
  2. When P1 Pin 5 is High (+5V / Bit 0), current flows through R2 into the base, turning the transistor ON (saturated). The collector pulls the USB adapter's RXD pin directly to 0V (Ground).
  3. The logic is cleanly inverted at nanosecond speed, perfectly recreating the standard 115,200 baud UART waveform!

7. Method B: FTDI Software Inversion (Zero Extra Components!)

If you use an official FTDI FT232R USB-UART adapter, you do not need any transistors or resistors! The FT232R silicon has internal configurable inverter gates built into its I/O pads.

Clean 3-Wire Connection Diagram

SMART METER P1 PORT (RJ11 or RJ12) FTDI FT232RL USB ADAPTER ================================== ======================== [ Pin 2: Data Request (RTS) ] ──────────────────── [ +5V (VCC) ] (Pulls RTS High) [ Pin 3: Data GND ] ────────────────────────────── [ GND ] [ Pin 5: Data TxD ] ────────────────────────────── [ RXD ] (Direct connection!)

Configuring FTDI RX Inversion via Linux (ftdi_eeprom)

You can permanently configure the FTDI adapter's EEPROM on your Raspberry Pi in 60 seconds:

# 1. Install the open-source ftdi-eeprom utility
sudo apt-get update && sudo apt-get install -y ftdi-eeprom

# 2. Create a temporary configuration file
cat << 'EOF' > ftdi_p1.conf
vendor_id=0x0403
product_id=0x6001
invert_rxd=true
EOF

# 3. Flash the inversion flag into the FTDI EEPROM
sudo ftdi_eeprom --flash-eeprom ftdi_p1.conf

# 4. Unplug and replug the USB adapter
# The adapter now natively inverts incoming serial bits in hardware!
🌟 Flashing via Windows (FT_Prog)

If you are on Windows, download the free FT_Prog utility from FTDI's official website. Plug in the adapter → Click Scan and Parse → Expand Hardware Specific → Invert RS232 Signals → Check the box for Invert RXD → Click Program (lightning bolt icon). Done!

8. Step-by-Step Cable Assembly & Verification

Step 1: Strip and Prepare the Cable

Remove 25 mm of the outer jacket from the telephone/UTP cable. Do not nick the inner conductor insulation. Strip 4 mm of insulation from each conductor strand.

Step 2: Crimp the RJ11 / RJ12 Connector

Hold the clear modular connector with the plastic locking tab facing away from you (down) and the gold contact blades facing up. Insert the wires from left to right:

  • For RJ12 (6P6C): Pin 1 (Leftmost, +5V optional) • Pin 2 (RTS Request) • Pin 3 (GND) • Pin 4 (NC) • Pin 5 (TxD Data) • Pin 6 (Rightmost, GND).
  • For RJ11 (4-wire flat cable): Wire 1 → Pin 2 (RTS) • Wire 2 → Pin 3 (GND) • Wire 3 → Pin 4 (NC) • Wire 4 → Pin 5 (TxD Data).

Push wires firmly until they bottom out against the front plastic end. Squeeze the crimper firmly until the ratchet releases.

Step 3: Solder the USB Adapter Connections

Connect the cable wires to your USB UART board according to Method A (with transistor) or Method B (direct FTDI). Ensure the voltage selection jumper on your USB-UART board is set to 5V (not 3.3V).

Step 4: Pre-Power Multimeter Verification (Crucial Safety Step!)

⚠️ Mandatory Multimeter Check Before Plugging In

Before inserting the cable into your utility smart meter, take your digital multimeter and set it to Continuity / Resistance (Ω) mode:

  • Probe between +5V (Pin 2 / USB 5V) and GND (Pin 3): Ensure there is NO short circuit (resistance must be infinite / OL).
  • Probe between TxD (Pin 5) and GND: Ensure no short circuit exists.

A short between +5V and GND could trip the smart meter internal polyfuse or damage your Raspberry Pi USB bus!

9. Activating the P1 Port with Your Grid Operator

In Belgium (Fluvius), the P1 user port is electronically locked by default to protect consumer privacy. You must request activation via the web portal before the meter will transmit data.

Fluvius Activation Steps (Flanders, Belgium)

  1. Go to www.fluvius.be and log in to your personal "Mijn Fluvius" portal.
  2. Navigate to Meters & Aansluitingen → Select your digital electricity meter (EAN code).
  3. Look for the section labeled "Poorten digitaal beheer (P1 en S1)".
  4. Click "Activeer gebruikerspoorten" and accept the privacy terms.
  5. Activation Time: The cellular grid network transmits an over-the-air activation command to your smart meter. This typically completes within 15 minutes to 72 hours.
  6. Visual Verification on Meter LCD: Look at your smart meter's digital display.
    • When LOCKED: A solid yellow/black padlock icon (🔒) appears above "P1".
    • When ACTIVE: The padlock icon disappears, and a small downward triangle (▼) appears above "P1", indicating the port is open and streaming!
💡 Netherlands Smart Meters (Liander, Enexis, Stedin)

In the Netherlands, smart meters under DSMR 4 and DSMR 5 have their P1 ports open and active by default out-of-the-box. No online activation request is required.

10. Linux Recognition & Raw Serial Verification

Plug your completed USB cable into any free USB port on your GEMS Raspberry Pi 5.

1. Verify USB Device Enumeration

Open Cockpit terminal on port 9090 or SSH into your Raspberry Pi and run:

dmesg | grep -E "ttyUSB|FTDI|ch341"

You should see output similar to:

[ 124.512] usb 1-1.2: FTDI USB Serial Device converter detected
[ 124.513] usb 1-1.2: Detected FT232RL
[ 124.514] usb 1-1.2: FTDI USB Serial Device converter now attached to ttyUSB0

2. Test Raw Telegram Stream in Terminal

Configure the serial terminal parameters (115,200 baud, 8 data bits, no parity, 1 stop bit) and read the live telegrams:

stty -F /dev/ttyUSB0 115200 cs8 -cstopb -parenb
cat /dev/ttyUSB0

Within 1 to 2 seconds, clean ASCII text telegrams will print on your screen:

  2. Click Settings in the navigation sidebar, then click the Devices tab.
  3. Click the + Add Device button.
  4. Select the Smart Meter category card.
  5. In the Template dropdown, select:
    • DSMR P1 RJ12 Serial Dongle (/dev/ttyUSB0) — for direct USB cable connection.

    Setting Name Recommended Value Installer Guidance & Explanation

  7. Click Add Device. The device card will immediately appear with a green ● Online badge, and live grid power will flow into your Dashboard!

13. Exhaustive Troubleshooting & Common Mistakes

Issue 1: Terminal shows completely garbled characters or question marks

Cause: Signal inversion is missing or incorrect baud rate.

  • Fix: Ensure your hardware inverter transistor (Method A) is correctly wired with collector pulled up to +5V and base driven through a 10 kΩ resistor. If using Method B, verify that invert_rxd=true was successfully flashed to the FTDI EEPROM.
  • Baud Rate: Verify baud rate is set to 115200 for Fluvius/DSMR 5. If your meter is an older DSMR 3 or 4, switch baud rate to 9600.

Issue 2: cat /dev/ttyUSB0 prints nothing at all (cursor just sits there)

Cause: Pin 2 (Data Request / RTS) is not pulled HIGH, or P1 port is electronically locked.

  • Check RTS Pin 2: Measure voltage between Pin 2 and Pin 3 with your multimeter. It must be +5.0V. If it is 0V, the smart meter will remain silent! Connect Pin 2 directly to the USB adapter's +5V VCC line.
  • Check P1 Lock: Look at your meter display. If there is a padlock icon (🔒) above "P1", the port is locked by the grid operator. Log into "Mijn Fluvius" and request port activation.

Issue 3: Linux reports "Permission denied" accessing /dev/ttyUSB0

Cause: The gems system user needs membership in the dialout group.

  • Fix: Run: sudo usermod -a -G dialout gems && sudo systemctl restart gems.

Issue 4: USB device name changes between reboots (e.g. from ttyUSB0 to ttyUSB1)

Cause: Multiple USB serial adapters plugged into the Raspberry Pi.

  • Fix: Use the persistent hardware serial path instead of generic /dev/ttyUSB0. In terminal, run:
    ls -l /dev/serial/by-id/
    Copy the permanent path (e.g. /dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A50285BI-if00-port0) and paste it directly into the Serial Port field in GEMS!
