Supported Device Templates & Step-by-Step Configuration Guides

GEMS includes 90 native hardware integration templates spanning 80+ leading manufacturers across solar inverters, home battery storage systems, EV charging stations, digital smart meters, and smart contactors.

Devices View: Categorized active devices displaying IP/serial endpoints, Modbus Slave IDs, real-time online status badges, and quick-action edit/delete controls.
Add Device Wizard: Interactive category cards, template dropdown, protocol-specific parameter fields, and instant input validation.

Universal 4-Step Device Onboarding Workflow

Adding and configuring any device in GEMS follows a simple, fully UI-driven 4-step process without touching any config files:

Step 1

Physical Connection & Local Network

Connect your device via Ethernet LAN, Wi-Fi, RS485 bus, or USB P1 cable. Ensure the device and GEMS are on the same local subnet. Use the built-in Scanner (accessible from the sidebar) to instantly discover your device IP address and MAC OUI vendor.

Step 2

Vendor App / Hardware Preparation

On your device or vendor mobile app, enable the communication protocol: enable Modbus TCP (e.g. in Huawei FusionSolar, SMA Speedwire, or SolarEdge SetApp), point your EV Charger's OCPP Server URL to GEMS, or toggle Local API on your HomeWizard or Shelly device.

Step 3

Add Device in GEMS UI

In GEMS, navigate to Settings → Devices → + Add Device. Select your category (Solar & Inverters, EV Chargers, Grid & Smart Meters, or Smart Relays), select your hardware template, enter the IP host/port or ChargeBox ID, and click Save Device.

Step 4

Verify Real-Time Polling Health

The background poller immediately starts querying your hardware. Check that the device card displays a green ● Online status. Head to the Dashboard to watch live energy flow animations and verify register telemetry in the Logger.

Step-by-Step Configuration Guides for Popular Inverters

Huawei SUN2000 Hybrid Inverters (with LUNA2000 Battery)

Template: huawei_inverter
  1. Enable Modbus TCP on SDongleA: Open the Huawei FusionSolar app as Installer. Navigate to Device Management → Dongle → Set Parameters → Modbus TCP. Set to Enable (Unrestricted) and confirm port 502 is open.
  2. Network Connection: Connect the SDongleA to your router via Ethernet or Wi-Fi. Find its IP address (e.g. 192.168.1.105) using the GEMS Scanner tab.
  3. Add in GEMS: In GEMS, click Settings → Devices → + Add Device.
    • Category: Inverters & Solar
    • Template: Huawei Hybrid Inverter
    • Device Name: Huawei SUN2000
    • Host IP: 192.168.1.105  |  Port: 502  |  Modbus ID: 1 (or 2 if cascading)
    • Rated Power (kW): Enter your inverter AC rating (e.g. 6.0)
    • Allow Curtailment: Check box if using Netherlands Zero-Export or capacity limits
  4. Verify: Click Save Device. Within 5 seconds, status will switch to green ● Online. PV production, battery SOC %, and battery charging/discharging power will populate on the Dashboard.

SMA Sunny Boy / Sunny Tripower / Sunny Island

Template: sma_inverter
  1. Enable Modbus & SunSpec: Open the SMA Web UI in a browser using your installer password. Go to Device Parameters → External Communication → Modbus → TCP Server. Enable TCP Server and verify Port 502. Set Unit ID to 126 (default) or 3.
  2. Add in GEMS: In GEMS, go to Settings → Devices → + Add Device.
    • Category: Inverters & Solar
    • Template: SMA Sunny Boy / Tripower
    • Host: SMA Inverter IP (e.g. 192.168.1.110)  |  Port: 502  |  Modbus ID: 126
    • Rated Power (kW): e.g. 8.0
  3. Verify: Status becomes ● Online. Real-time active generation and connected battery telemetry are streamed to the Dashboard.

SolarEdge Inverters (Single-Phase & 3-Phase with SetApp)

Template: solaredge_inverter / solaredge_3phase
  1. Enable SunSpec in SetApp: Open the SolarEdge SetApp mobile application, connect to the inverter's Wi-Fi hotspot, navigate to Communication → Modbus TCP. Toggle to Enabled and set port to 1502 (standard SolarEdge default) or 502. Verify Device ID is set to 1.
  2. Add in GEMS: Choose template SolarEdge Inverter (single phase) or SolarEdge 3-Phase Inverter. Enter Host IP, Port 1502, Modbus ID 1.
  3. Verify: Real-time SunSpec telemetry will flow immediately to GEMS.

Victron GX (Cerbo GX / MultiPlus-II / Venus OS)

Template: victron_inverter
  1. Enable Modbus TCP in Venus OS: Access the Victron Remote Console (via browser or Touch 50/70). Go to Settings → Services → Modbus TCP and switch to ON.
  2. Add in GEMS: Template Victron Inverter/GX. Set Host IP, Port 502, Modbus ID 100 (system overview) or 228 (grid inverter).

Sungrow Hybrid Inverter (SH5.0 - SH10RT)

Template: sungrow_inverter
  1. Direct LAN Port Connection: For reliable, fast Modbus TCP polling, connect your Ethernet cable directly to the inverter's internal LAN RJ45 port (under the lower cover), rather than the external WiNet-S dongle.
  2. Add in GEMS: Select Sungrow Inverter. Host IP, Port 502, Modbus ID 1.

2. EV Charging Stations & Wallboxes (38 Templates)

GEMS supports EV chargers via Modbus TCP direct fieldbus (preferred), Universal Native OCPP (1.6-J & 2.0.1) WebSocket server, and Local REST APIs. Chargers support automated Eco mode (excess solar charging), Flanders capacity peak shaving, and dynamic 1-phase / 3-phase power throttling.

EV Charger Configuration Form: Charge modes (Eco, PV Only, Fast, Off), max charge current (A), Modbus TCP parameters, and native OCPP server parameters.
⚡ Modbus TCP Integration (Recommended & Preferred)

Modbus TCP is the preferred connection method for EV chargers due to significant technical advantages:

  • Sub-Second Real-Time Throttling: Direct Modbus register writes allow instantaneous current adjustments (6A to 32A), critical for Flanders capacity tariff peak shaving and rapid solar curtailment.
  • Simultaneous CPO / Reimbursement Coexistence: If your charger is tied to an employer charge card, split-billing system, or external Charge Point Operator (e.g. E-Flux, Road, Optimile, Easee Cloud) over OCPP, GEMS controls charge speed locally via Modbus TCP without interfering with or disconnecting your cloud billing connection.
  • Robust Local Operation: Deterministic, low-overhead communication over standard TCP port 502 with zero cloud dependencies.

How to configure: Enable Modbus TCP in your charger's web portal or installer app. In GEMS, click Add Device → EV Charger, select your brand template (e.g. Alfen Eve, Keba KeContact P30, Mennekes Amtron, Webasto Live/Next, ABB Terra AC, Raedian Gemini/Neo, Phoenix Contact Charx, Veton, SolarEdge Home EVSE, or Generic Modbus TCP Charger), enter the charger's local IP address, Port 502, and Modbus Slave ID (typically 1).

Native OCPP Server (Port 8887 / 8080) (Alternative)
For chargers without Modbus TCP or standalone residential setups without third-party CPO billing platforms, GEMS runs a built-in Native OCPP 1.6-J & 2.0.1 WebSocket server on port 8887:
ws://<GEMS-IP>:8887/<ChargePointID>
Example: If GEMS IP is 192.168.1.188 and your charger ID is EVB-P201948, set URL to ws://192.168.1.188:8887/EVB-P201948. Select the OCPP 1.6J / 2.0.1 Smart EV Charger template in GEMS and enter the same ID.

RAEDIAN NEO / NEX / Gemini AC Wallbox (Modbus TCP)

Template: raedian_charger
  1. Network Connection: Connect your RAEDIAN wallbox to your home Wi-Fi or Ethernet network. Use the RAEDIAN app to confirm its local IP address (e.g. 192.168.1.120). Modbus TCP port 502 is enabled by default.
  2. Add in GEMS: In GEMS, go to Settings → Devices → + Add Device.
    • Category: EV Chargers
    • Template: RAEDIAN NEO / NEX AC Wallbox
    • Device Name: RAEDIAN Wallbox 22kW
    • Host IP: 192.168.1.120  |  Port: 502  |  Modbus ID: 1 (or 2 for Connector B)
    • Charging Mode: Choose Eco (Solar Priority) or Fast.
  3. Verify: Click Save Device. The status switches to ● Online. When a vehicle plugs in, GEMS monitors real-time charging wattage and automatically modulates current setpoints between 6A and 32A according to your solar excess and Flanders peak capacity limits.

Universal OCPP 1.6-J Charger (Huawei FusionCharge, EVBox, Mennekes, SMA, Siemens)

Template: ocpp / huawei_scharger / evbox_charger / mennekes_ocpp
  1. Determine ChargePoint ID: Identify the unique ChargePoint ID of your wallbox (e.g., serial number or custom string like WALLBOX-01).
  2. Configure CSMS Backend in Wallbox: In your wallbox configuration app or web interface, set the Central System URL to:
    ws://192.168.1.188:8887/WALLBOX-01
    (Replace 192.168.1.188 with your GEMS IP address, and WALLBOX-01 with your ChargePoint ID).
  3. Add in GEMS: In GEMS, select Settings → Devices → + Add Device → EV Chargers → Select your brand template (e.g. EVBox Elvi or Huawei FusionCharge). Enter your ChargePoint ID.
  4. Verify: GEMS accepts the WebSocket handshake, registers the charger heartbeat, and displays live charging metrics.

go-e Charger Gemini / HOMEfix / PRO (Local HTTP REST)

Template: goe_charger
  1. Enable Local HTTP API v2: Open the go-e Charger mobile app → Settings → Connectivity → Advanced → Local HTTP API v2. Toggle to Enabled.

Step-by-Step Guides for Smart Meters

P1 Smart Meter (USB / Serial Cable for Fluvius & Dutch DSMR)

Template: p1_serial
  1. Hardware Wiring: Plug your RJ12 P1 cable into the digital smart meter P1 port (Fluvius Belgium, Enexis/Liander Netherlands). Plug the USB end into any USB port on your Raspberry Pi.
    Fluvius Belgium users: Make sure the P1 customer port is activated via the online Mijn Fluvius portal!
  2. Add in GEMS: In GEMS, click Settings → Devices → + Add Device.
    • Category: Grid & Smart Meters
    • Template: P1 Smart Meter (USB/Serial)
    • Serial Port: Select /dev/ttyUSB0 (auto-detected by GEMS)
    • Baud Rate: 115200 (Standard for DSMR 4.x & 5.x) or 9600 (older DSMR 2.x/3.x)
    • Poll Interval: 2 seconds
  3. Verify: Status turns ● Online. Grid import/export power, voltage per phase, and total kWh meter counters appear on the Dashboard Grid node.

HomeWizard Wi-Fi P1 Meter & Energy Socket

Template: homewizard_meter
  1. Enable Local API in HomeWizard App: In the HomeWizard Energy mobile app, go to Settings → Meters → Your P1 Meter → Local API and switch the toggle to ON.
  2. Add in GEMS: Select HomeWizard Meter template. Enter the HomeWizard IP (e.g. 192.168.1.130) and Port 80.
  3. Verify: GEMS reads /api/v1/data every 2 seconds with zero cloud latency.

Shelly Pro 3EM / Gen3 3EM-63T (3-Phase Submeter)

Template: shelly_pro_3em

  2. Add in GEMS: Select template Shelly Pro 3EM / Gen3 3EM-63T. Enter IP address (e.g. 192.168.1.140) and port 80.
  3. Verify: Active power across all 3 phases is read instantly via Gen 2/3 RPC.

6. Plugin Architecture & Contributing Templates

GEMS is architected as an extensible Go plugin framework located in backend/internal/templates/. Every hardware template implements the unified DevicePoller interface: 

package templates

import (
    "gems/internal/models"
)

type MyDevicePoller struct {
    device models.Device
}

func init() {
    Register(Template{
        Metadata: TemplateMetadata{
            ID:       "my_device_template",
            Name:     "Brand Model Inverter/Charger",
            Type:     "modbus", // "modbus", "ocpp", "rest", "serial", "network", "cloud"
            Category: "Inverters & Solar",
            Vendor:   "BrandName",
        },
        NewPoller: func(d models.Device) models.DevicePoller {
            return &MyDevicePoller{device: d}
        },
    })
}

func (p *MyDevicePoller) Poll() (models.Telemetry, error) {
    // Read Modbus registers or REST endpoint and return standardized Telemetry struct
}
