Manuel de Connexion Compteur Communicant Port P1 & Câble DIY

Raccordez directement votre système de gestion énergétique GEMS au compteur numérique d'électricité du gestionnaire de réseau. Lisez la télémétrie réseau haute fréquence chaque seconde, surveillez les pointes quart-horaires fiscales et apprenez à assembler votre propre câble fiable USB vers RJ11/RJ12 pour moins de 5 €.

⚡ Pourquoi le port P1 est le capteur réseau de référence

Bien que les compteurs d'énergie Modbus externes (tels que l'Eastron SDM630 ou le Shelly Pro 3EM) soient excellents, le port client P1 du compteur communicant fournit les mesures fiscales exactes utilisées pour calculer votre facture d'électricité et le tarif capacitaire flamand (capaciteitstarief).

En connectant GEMS directement au port P1, le contrôleur lit le registre officiel de pointe mensuelle maximale OBIS 1-0:1.6.0 sans aucun écart par rapport au décompte de votre fournisseur.

2. Brochage physique RJ12 (6P6C) vs RJ11 (6P4C)

La prise P1 du compteur est un connecteur modulaire à 6 contacts. Un câble téléphonique standard à 4 fils (RJ11 6P4C) s'insère directement sur les 4 broches centrales de cette embase 6 broches :

Broche prise Signal Fonction électrique RJ12 (6P6C) RJ11 (6P4C)
Broche 1 Alimentation +5V Sortie +5 VDC (jusqu'à 250 mA en DSMR 5.0). Alimente les dongles externes. Fil 1 Non utilisé (alimenté par USB)
Broche 2 Demande de données (RTS) Entrée de commande. Doit être tirée à l'état HAUT (+5V) pour démarrer l'envoi des télégrammes. Fil 2 Fil 1
Broche 3 Masse données (GND) Masse de référence du signal. Fil 3 Fil 2
Broche 4 Réservé (NC) Non connecté. Fil 4 Fil 3
Broche 5 Sortie données (TxD) Ligne de données à collecteur ouvert inversé. Fil 5 Fil 4
Broche 6 Masse alimentation (GND) Masse de référence (reliée en interne à la Broche 3). Fil 6 Non utilisé

3. Inversion du signal expliquée (pourquoi une liaison directe échoue)

Contrairement aux ports série TTL classiques où une ligne au repos reste à +5V et un 0 binaire tire vers 0V, l'interface P1 DSMR / Fluvius / ORES utilise une logique à collecteur ouvert inversée :

  • Ligne au repos (Idle) : Transistor ouvert / tiré à 0V → Niveau logique 1
  • Transmission active : Tirée à +5V → Niveau logique 0

Si vous reliez directement la Broche 5 à un adaptateur série USB standard, Linux lit des bits inversés, ce qui génère des erreurs de trame et des caractères illisibles. Vous devez inverser le signal soit de manière matérielle (Méthode A), soit dans le micrologiciel EEPROM FTDI (Méthode B).

5. Méthode A : Montage inverseur matériel à transistor

Ce schéma fonctionne universellement avec n'importe quel adaptateur USB-UART :

PORT P1 (RJ11/RJ12)                             ADAPTATEUR USB-UART
===================                             ===================

[ Broche 2: RTS ] ─────────────────────────────── [ +5V VCC ] (Tire RTS à l'état haut)

[ Broche 3: GND ] ─────────────────────────────── [ GND ]

                                     │
                                    ┌┴┐
                                    │ │ R1 (1 kΩ Pull-up)

                                     ├─────────── [ Broche RXD ] (TTL inversé)
                                     │
                                   C │
[ Broche 5: TXD ] ───[ 10 kΩ R2 ]────┤  BC547 NPN
                                   B ╲
                                     │ E
                                     │
[ Broche 3/6: GND ] ─────────────────┴─────────── [ Broche GND ]

6. Méthode B : Inversion logicielle FTDI à 3 fils (aucun composant externe !)

Si vous utilisez un adaptateur officiel FTDI FT232RL, vous pouvez inverser la broche RX directement dans l'EEPROM logicielle sans aucun transistor : 

PORT P1 (RJ11/RJ12)                             ADAPTATEUR FTDI FT232RL
===================                             =======================

[ Broche 2: RTS ] ─────────────────────────────── [ +5V VCC ] (Tire RTS à l'état haut)

[ Broche 3: GND ] ─────────────────────────────── [ GND ]

[ Broche 5: TXD ] ─────────────────────────────── [ RXD ] (Liaison directe !)

Flashage EEPROM sous Linux en 60 secondes

sudo apt-get update && sudo apt-get install -y ftdi-eeprom

cat << 'EOF' > ftdi_p1.conf
vendor_id=0x0403
product_id=0x6001
invert_rxd=true
EOF

sudo ftdi_eeprom --flash-eeprom ftdi_p1.conf
# Débranchez puis rebranchez le dongle USB. Terminé !

7. Activation du port P1 (Mijn Fluvius / ORES / RESA)

En Belgique, le port client P1 doit être activé gratuitement auprès de votre gestionnaire de réseau (par ex. via Mijn Fluvius en Flandre ou l'espace client ORES / RESA / Sibelga) :

  1. Connectez-vous sur Mijn Fluvius (ou le portail de votre GRD wallon/bruxellois).
  2. Rendez-vous dans Meters & Aansluitingen (Compteurs & Raccordements) → Sélectionnez le code EAN de votre compteur électrique.
  3. Sous Poorten digitaal beheer (P1 en S1), cliquez sur Activeer gebruikerspoorten (Activer les ports utilisateur).
  4. L'activation à distance prend entre 15 minutes et 72 heures.
  5. Confirmation sur l'écran du compteur : L'icône de cadenas (🔒) au-dessus de « P1 » disparaît et est remplacée par un petit triangle (▼).

8. Configuration du compteur intelligent dans l'interface GEMS

  1. Ouvrez GEMS sur http://ems.local → Paramètres → Appareils (déverrouillez le Mode Installateur via l'icône de cadenas).
  2. Cliquez sur Détecter les appareils série (ou passez par Scanner → Analyser les ports série → + Configurer) pour identifier automatiquement le chemin persistant /dev/serial/by-id/* et le débit en bauds (115200 ou 9600) de votre câble P1.
  3. Alternativement, sélectionnez Compteur Intelligent → DSMR P1 RJ12 Serial Dongle, cliquez sur Détection auto à côté du champ Port série et réglez l'intervalle d'interrogation sur 1s.
  4. Cliquez sur Ajouter un appareil. Vérifiez l'indicateur vert ● En ligne et visualisez vos flux énergétiques en direct sur le Tableau de bord !

9. Dépannage & erreurs fréquentes

Symptôme Cause probable Solution
Caractères illisibles dans le terminal Signal non inversé ou débit en bauds incorrect Vérifiez le montage à transistor ou l'option FTDI invert_rxd. Réglez le débit sur 115200.
Aucune donnée / curseur figé sur cat /dev/ttyUSB0 Broche 2 (RTS) non tirée à +5V ou port P1 verrouillé Mesurez la présence de 5,0V sur la Broche 2 au multimètre. Vérifiez l'absence du cadenas sur l'écran LCD du compteur.
Erreur Linux « Permission denied » sur /dev/ttyUSB0 Utilisateur système gems absent du groupe dialout Exécutez sudo usermod -a -G dialout gems && sudo systemctl restart gems.
Avertissements intermittents DSMR CRC mismatch Couplage CEM sur câble RJ12 non blindé ou doubleur P1 passif GEMS draine automatiquement le flux 1 Hz et relit immédiatement la trame suivante ; séparez le cordon RJ12 des câbles AC de puissance et privilégiez un répartiteur P1 actif.
