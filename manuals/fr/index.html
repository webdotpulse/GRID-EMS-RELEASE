Documentation GEMS

Architecture système & Philosophie

GEMS est conçu comme une application unifiée haute performance destinée à fonctionner en continu 24h/24 avec une empreinte mémoire minimale.

Protection de la carte SD & Optimisation du stockage Raspberry Pi

Les écritures en base de données sont mises en mémoire tampon et regroupées en transactions atomiques chaque minute. Associée au mode Write-Ahead Logging (WAL) de SQLite et aux partitions temporaires en RAM, cette architecture réduit les cycles d'écriture sur carte SD de plus de 98 % par rapport aux systèmes de journalisation classiques.

Couche Technologie Responsabilités principales
Moteur Backend Go (Golang 1.24) Serveur HTTP unifié, boucles d'interrogation matérielle (1s/5s), boucles de régulation, récupération des prix spot Day-Ahead et serveur WebSocket OCPP natif.
Base de données & Séries temporelles SQLite 3 (mode WAL) Stockage local léger, tampons d'agrégation en mémoire vive et tâche automatisée de purge à 90 jours de rétention.
Interface Frontend SPA Vue 3 + TypeScript + Tailwind CSS Tableau de bord réactif, vecteurs SVG PowerFlow animés, graphiques temporels Chart.js et configuration 100 % graphique sans fichiers YAML.
Télémétrie temps réel Server-Sent Events (SSE) Diffusion unidirectionnelle inférieure à la seconde (/api/live) éliminant la surcharge liée aux requêtes AJAX répétées.
Système & Affichage Wayfire + Chromium Kiosk Compositeur Wayland minimaliste lançant automatiquement Chromium sur http://ems.local sans environnement de bureau lourd.

Guide de démarrage rapide en 5 minutes

Mettez votre unité GEMS en service en trois étapes simples :

Écrire l'image Raspberry Pi précompilée

Téléchargez la dernière archive officielle et écrivez-la sur une carte MicroSD (8 Go minimum) ou un SSD NVMe à l'aide de BalenaEtcher ou Raspberry Pi Imager :

Bash / Terminal 
# 1. Télécharger la dernière image depuis GitHub
curl -LO https://github.com/webdotpulse/GRID-EMS-RELEASE/releases/latest/download/gems-os-image.img.xz

# 2. Flasher sur carte SD ou SSD NVMe avec BalenaEtcher ou Raspberry Pi Imager
# (Sélectionnez directement gems-os-image.img.xz sans décompression manuelle)

Insérer le support et mettre sous tension

Raccordez votre Raspberry Pi à votre réseau local par câble Ethernet (recommandé), puis branchez l'alimentation.

Ouvrez un navigateur web sur n'importe quel smartphone, tablette ou PC connecté au même réseau et accédez à :

URL du navigateur 
http://ems.local
# Ou directement via l'adresse IP :
http://<raspberry-pi-ip>:8080

Découvrir et ajouter vos équipements

  1. Rendez-vous dans Paramètres → Appareils.
  2. Utilisez le Scanner pour identifier automatiquement vos onduleurs Modbus, compteurs intelligents P1 et bornes de recharge VE.
  3. Cliquez sur Ajouter un appareil énergétique, choisissez le modèle correspondant (ex. Solis Hybrid Inverter, RAEDIAN Wallbox ou Compteur P1), testez la connexion et enregistrez.
  4. Revenez sur le Tableau de bord pour visualiser vos flux énergétiques PowerFlow en temps réel !
Aucun fichier de configuration requis

GEMS ne nécessite jamais l'édition manuelle de fichiers YAML ou JSON. Tous les paramètres d'appareils, registres Modbus, contrats tarifaires et seuils de stratégie se configurent dynamiquement depuis l'interface web intuitive.
