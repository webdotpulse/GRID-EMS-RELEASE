Huawei SUN2000, LUNA2000 & FusionSolar Commissioning Manual

Complete field configuration manual covering every parameter to set inside the Huawei FusionSolar App (SDongleA-05, EMMA-A02, LUNA2000-S0/S1, and Active Power Control) and how to configure GEMS for optimal peak shaving, solar self-consumption, and Day-Ahead arbitrage.

1. Supported Huawei Ecosystem & Connection Topologies

GEMS executes all telemetry reads, LUNA2000 battery charge/discharge setpoints, and solar curtailment locally over your LAN or RS-485 bus while preserving normal FusionSolar cloud monitoring.

Topology Physical Connection Best-Practice Recommendation
Topology A: SDongleA-05 (WLAN-FE) Plug an Ethernet RJ45 cable inside the SDongleA-05 housing. GEMS connects to TCP port 502 (Modbus ID 1). Pair with a USB P1 Smart Meter on GEMS. Recommended Gold Standard. Always prefer wired Ethernet on the SDongleA-05 over 2.4 GHz Wi-Fi to eliminate wireless jitter and timeouts.
Topology B: Huawei EMMA-A02 Connect EMMA-A02 via Ethernet to LAN. Onboard both huawei_emma (meter) and huawei_inverter (Slave ID 1) pointing to the EMMA IP on port 502. Ideal for LUNA2000-S1 / MAP0 / MB0 sites. GEMS multiplexes both devices cleanly over one pooled TCP connection.
Topology C: Direct USB-to-RS485 Shielded twisted-pair cable (`9600 bps, 8N1`, Slave ID `1`) from GEMS USB-RS485 to SUN2000 COM port (`L1`: Pin 2=A+, Pin 1=B-; `M1`: Pin 1=A+, Pin 3=B-). Only when NO SDongleA-05 or EMMA-A02 is installed (an installed dongle claims master control of the internal RS-485 bus).
Topology D: P1-Driven LUNA2000 (No EMMA / No Huawei Meter) SUN2000 + LUNA2000 without DTSU666-H or EMMA, paired with a utility P1 Smart Meter on GEMS (Grid Meter Connected? = Unchecked). GEMS actively drives LUNA2000 solar charging, household load discharging, and grid arbitrage from P1 meter readings. Keep Charge from AC = Enable in FusionSolar; if Self-Consumption is unavailable without a Huawei meter, select Fixed Charge/Discharge (0 slots).

2. Mandatory Firmware & Network Rules

  • Minimum Firmware Versions: Ensure SDongleA-05 runs at least V100R001C00SPC126 or V200R022C10SPC108+ (recommended V200R022C10SPC118+), SUN2000-L1 runs SPC130+, SUN2000-M1 runs SPC153+, LUNA2000 runs SPC119+ / SPC624+, and EMMA-A02 runs V100R023C10SPC100+.
  • Single Modbus TCP Master Rule: Both SDongleA-05 and EMMA-A02 accept only one concurrent TCP client on port 502. Stop any secondary external Modbus polling scripts or direct wallbox pollers before connecting GEMS.
  • Static IPv4 / DHCP Reservations: Fix the IPv4 addresses of both your GEMS appliance and the Huawei SDongleA-05 / EMMA-A02 in your router's DHCP table.

3. Step-by-Step Huawei FusionSolar App Settings

Use Local Device Commissioning (Installer Login): Homeowner plant accounts hide Modbus TCP and grid-control settings. Turn OFF mobile cellular data on your phone (leave Wi-Fi ON), open the FusionSolar App → Me (or Services) → Device Commissioning, scan the QR code on the inverter (or EMMA-A02), and log in as Installer.

3.1 Unlocking Modbus TCP on SDongleA-05

  1. Navigate to Settings → Communication Configuration → Dongle Parameter Settings → Modbus-TCP.
  2. Change Connection to Enable (unrestricted) (or Enable (restricted) set to the static IPv4 of your GEMS controller) and tap Confirm.
  3. Under Settings → Communication Configuration → RS485_1, confirm Protocol = MODBUS, Baud Rate = 9600, and note the Communication Address (default 1).
  4. Remote Web Portal Alternative: Log into FusionSolar Web as Installer → Plants → Device Management → Select SDongle → Configuration → Connection Parameters → Modbus TCP → Enable (unrestricted).

3.2 Unlocking Modbus TCP on Huawei EMMA-A02

  1. Connect to the EMMA-A02 via Device Commissioning as Installer.
  2. Navigate to Settings → Communication Configuration → Modbus TCP.
  3. Set Connection = Enable and TLS Encryption = Disable (OFF).
  4. Set Client IP Address to the exact static IPv4 address of your GEMS controller (e.g. 192.168.1.50). Never enter 0.0.0.0—EMMA-A02 rejects wildcard entries!
  5. Keep EMMA's own cloud AI / Time-of-Use battery scheduler Disabled (leave battery mode on Maximum Self-Consumption).

3.3 Complete LUNA2000 Battery & Active Power Checklist in FusionSolar

Under Settings → Energy Control and Settings → Power Adjustment → Active Power Control, verify every setting below:

FusionSolar Parameter Required Value Why This Is Required
Working Mode Maximum Self-Consumption Hardware baseline restored automatically whenever GEMS releases active forced charge/discharge. Never select Time-of-Use (TOU) or Huawei's internal timers will conflict with GEMS.
Charge from AC Enable Unlocks permission for GEMS to trigger cheap/negative spot-price charging and winter low-SOC recovery (does not cause spontaneous grid charging during normal self-use).
Grid Charge Cutoff SOC 100 % Ensures Huawei firmware never prematurely blocks GEMS from reaching 95%–100% SOC during negative electricity prices.
Max Charge / Discharge Power Hardware Rated Max
(2500 / 5000 / 10500 W)		 Provides full throughput for solar capture and instantaneous Flanders 15-minute capacity peak shaving.
End-of-Charge SOC 100 % Required for periodic LiFePO4 cell top-balancing and accurate BMS SOC calibration.
End-of-Discharge SOC 5 % – 10 % (Standard)
15 % – 20 % (Backup Box)		 Set 5% in summer, 10% in winter, or 15%–20% when paired with a Huawei Backup Box / SmartGuard.
Active Power Control Mode Unlimited (No Limit) Avoid static zero-export inside FusionSolar so GEMS can export during profitable / Flemish GSC hours and dynamically curtail only during negative net return hours.
Closed-Loop Controller Inverter (Single) / SDongle (Cascade) Select Inverter on single-inverter sites for sub-second hardware regulation; select SDongle / SmartLogger only on multi-inverter cascades.

4. Onboarding Huawei Hardware in GEMS

Unlock Certified Installer Mode via the padlock icon 🔒 in Settings, onboard your primary utility meter first (P1 Serial Meter or Huawei EMMA-A02), and then add Settings → Devices → Inverter / Solar → Huawei Hybrid Inverter:

Step 1: Choose Inverter / Solar under Add New Device
Step 2: Enter Host IP, Port 502, Modbus ID 1, Rated kW, Poll 10s & Hybrid Flags
  • IP Address / TCP Port / Modbus ID: Enter the static IP of your SDongleA-05 or EMMA-A02, Port 502, and Modbus ID 1 (for cascaded inverters, add a second device with Modbus ID 2).
  • Rated Power (kW) & Allow Curtailment: Enter the exact AC nameplate kW (e.g. 4.6, 5.0, 10.0) and check Allow Curtailment so GEMS can issue exact 0.1% resolution derating setpoints.
  • Poll Interval: Keep at the auto-selected 10 seconds on SDongleA-05 (use 5 seconds only on wired EMMA-A02 or direct RS-485).
  • Grid Meter Connected?: Check ✓ whenever a Huawei DTSU666-H, DDSU666-H, or EMMA-A02 is wired to the Huawei system. Leave unchecked only when operating without a Huawei power sensor so GEMS drives LUNA2000 self-consumption from your P1 meter.
  • Battery Connected? & Capacity (kWh): Check ✓ and enter total usable LUNA2000 capacity (e.g. 5.0, 10.0, 15.0, 6.9, 13.8, 20.7 kWh).

5. Configuring GEMS for Optimal Working Conditions

Flanders Peak Shaving, Smart Adaptive Ceiling & Flemish GSC Protection
Dynamic 24h Forecast, 0.04 €/kWh Wear Cost & Winter Fallback
  1. Location & Solar Forecast (`Settings → Strategy`): Set Time Zone, click Lookup Lat/Lon on your street address, and enable Open-Meteo Solar Forecast Ingestion so LUNA2000 never grid-charges overnight ahead of a sunny morning.
  2. Regional Mode:
    • Flanders: Flanders Mode (Peak Shaving), Capacity Peak Limit = 2.5 kW (or 3.0–3.5 kW with heat pump + EV), Peak Shaving Buffer = 200 W (250 W on Wi-Fi SDongle), Ramp-up Hysteresis = 500 W, plus exact Flemish GSC value (`€0`, `€250`, `€350`, `€450`).
    • Netherlands: Netherlands Mode (Smart Saldering) + Active Inverter Curtailment at 0.00 €/kWh.
    • Fixed / Dual-Tariff: Eco (Max Self-Consumption).
  3. LUNA2000 Arbitrage & Longevity: Select your exact supplier contract under Settings → Energy Contract, then set Charging Strategy Mode = Dynamic 24h Forecast, Battery Wear Cost = 0.04 €/kWh (prevents unprofitable micro-cycling), Grid Charge Ceiling = 0.08 €/kWh, Grid Discharge Floor = 0.35 €/kWh, and enable Winter / Low-Solar Grid Charge Fallback (Trigger 25% → Target 65% over 2–3 cheapest hours).

5.4 Coordinating EV Chargers (Raedian) Without Emptying LUNA2000

Onboard your EV wallbox (such as a Raedian NEO / NEX / Gemini) directly in GEMS via Modbus TCP. For daytime solar surplus charging, select PV Only or Eco. If you boost EV charging during cheap overnight grid hours and want to preserve your LUNA2000 charge for the morning household peak, add a Battery Cost Optimization Rule with Action = Hold (Idle / No Export) matching your night EV window (e.g. 01:00 – 05:00).

6. Quick Troubleshooting Reference

Symptom Probable Cause Resolution
Connection refused / TCP RST on :502 Modbus TCP disabled, or EMMA-A02 TLS ON / wrong client IP Set SDongle Modbus-TCP = Enable (unrestricted); on EMMA-A02 disable TLS and whitelist exact GEMS IPv4 (never 0.0.0.0).
Intermittent i/o timeout drops Second Modbus master on port 502, weak Wi-Fi, or Poll < 8s Stop other polling clients, connect Ethernet RJ45 inside SDongleA-05, and keep GEMS Poll Interval at 10s.
LUNA2000 ignores forced grid charge or logs server device failure Charge from AC disabled in FusionSolar, meterless Topology D locked in a meter-dependent mode, or old SDongle FW Enable Charge from AC, set Grid Charge Cutoff SOC = 100%, uncheck Grid Meter Connected? in GEMS when no Huawei meter is wired (using Fixed Charge/Discharge with 0 slots if FusionSolar blocks Self-Consumption), and update SDongle FW.
Battery charges when house load rises Reversed DTSU666-H CT clamps or swapped phase taps Ensure CT arrows (K → L) point Grid → House and phase voltages match CT phases.
