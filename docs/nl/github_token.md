# Hoe maakt u een GitHub-token aan

> 🌐 **Taal / Langue / Language:** [English](../github_token.md) | **Nederlands** | [Français](../fr/github_token.md)

Om GEMS te configureren zodat het kan controleren op software-updates en deze kan installeren zonder tegen IP-snelheidslimieten (rate limits) van de GitHub-API aan te lopen, kunt u een GitHub Personal Access Token (classic) instellen.

1. Ga naar de instellingen van uw GitHub-account (*Settings*).
2. Navigeer naar **Developer settings -> Personal access tokens -> Tokens (classic)**.
3. Genereer een nieuw token. *(U heeft de `repo`-scope enkel nodig als de doelrepository privé is).*
4. Kopieer het token en plak het in de GEMS-webinterface onder **Instellingen -> Systeeminformatie**.
